# 🌱 Meu Ritmo

> **Uma tarefa de cada vez. Um passo de cada vez. No teu ritmo. 💜**

O **Meu Ritmo** é um projeto de rotina e foco criado com uma ideia simples: tornar a organização das tarefas mais **leve, clara, acessível e acolhedora**.

A proposta é ajudar a pessoa a começar uma tarefa sem transformar a organização do dia em mais uma fonte de pressão.

## 💜 Por que o Meu Ritmo?

Muitos aplicativos de produtividade oferecem muitas informações, recursos e etapas. Para algumas pessoas, isso pode acabar tornando a experiência confusa e cansativa.

O Meu Ritmo nasceu da vontade de criar uma alternativa mais simples:

- 🌱 uma tarefa de cada vez;
- 👣 pequenos passos para começar;
- 💜 uma experiência acolhedora;
- ♿ acessibilidade desde o início;
- 🧭 mais autonomia e menos complicação.

## 🎯 Objetivo

Criar uma ferramenta simples para ajudar na organização da rotina, no início das tarefas e na manutenção do foco, respeitando o ritmo de cada pessoa.

O projeto também considera uma experiência confortável para diferentes perfis de usuários, incluindo pessoas que podem se beneficiar de uma interface mais simples, clara e acessível.

## ✨ Ideia principal

O Meu Ritmo parte de uma pergunta simples:

**"O que eu consigo fazer agora?"**

Em vez de tentar organizar tudo de uma vez, a proposta é começar pelo próximo pequeno passo.

> **Uma tarefa de cada vez.  
> Um passo de cada vez.  
> No teu ritmo. 💜**

## 🛠️ Tecnologias

Neste momento, o projeto está sendo desenvolvido com tecnologias fundamentais da Web:

- HTML5
- CSS3
- JavaScript

A ideia é construir primeiro uma base sólida com o **feijão com arroz bem feito** antes de partir para tecnologias ou estruturas mais complexas.

## 📱 Direção do projeto

O Meu Ritmo está sendo pensado com uma abordagem **mobile-first**, buscando uma experiência simples e confortável também em telas menores.

Entre os princípios que orientam o desenvolvimento estão:

- simplicidade;
- clareza;
- acessibilidade;
- conforto visual;
- autonomia;
- facilidade de uso;
- linguagem acolhedora.

## 🚧 Status

**Em desenvolvimento.**

Esta é uma primeira versão do projeto e novas funcionalidades serão construídas aos poucos.

O objetivo não é colocar tudo de uma vez, mas evoluir o projeto de forma gradual e consciente.

## 🌱 Próximos passos

Algumas ideias que poderão fazer parte da evolução do projeto:

- melhorias na experiência visual;
- recursos de acessibilidade;
- organização das tarefas;
- pequenos passos para cada tarefa;
- recursos de foco;
- interação mais acolhedora;
- melhorias para dispositivos móveis.

As funcionalidades serão adicionadas conforme o projeto evoluir.

## ♿ Acessibilidade

A acessibilidade não é tratada como um recurso adicional no Meu Ritmo.

Ela faz parte da ideia do projeto desde o começo.

A intenção é buscar uma interface com:

- textos claros;
- boa legibilidade;
- contraste adequado;
- interação simples;
- menos elementos desnecessários;
- experiência confortável em diferentes dispositivos.
